# Добро пожаловать на урок по Git и удалённым репозиториям!

## 📋 Начало работы

1. **Зарегистрируйся и создай Токен:**
   - Нажми на свой аватар справа сверху → **Настройки** → **Токены доступа** (Access Tokens).
   - Создай новый токен: имя `course`, срок `1 месяц`, права: **write_repository** (или `api`).
   - **Скопируй токен** и сохрани его в надёжное место!

2. **Отметься в задаче:**
   - Перейди во вкладку **Задачи** (Issues) в этом репозитории.
   - Открой задачу **«Добавление в репозиторий»**.
   - Напиши в комментариях только свой **никнейм** (например: `ivan_dev`).
   - *Учитель увидит твой ник и добавит тебя в участники проекта.*

3. **Склонируй репозиторий и настрой Git:**
   ```bash
   git clone https://<ТВОЙ_ТОКЕН>@gitverse.ru/ЛОГИН_УЧИТЕЛЯ/НАЗВАНИЕ_РЕПО.git
   cd НАЗВАНИЕ_РЕПО
   git config --global user.name "Твоё Имя"
   git config --global user.email "твоя@почта.com"
   ```

---

## ⚠️ Золотое правило работы в этом репозитории

Чтобы не создавать конфликтов с другими студентами, мы работаем **только в своих личных ветках**.

**Подготовка твоей рабочей среды:**
1. Создай свою **базовую личную ветку** от главной:
   ```bash
   git checkout main
   git checkout -b feature/<твой_ник>
   ```
2. Все последующие задания выполняй в **новых ветках, созданных на основе твоей базовой ветки**:
   ```bash
   git checkout feature/<твой_ник>
   git checkout -b feature/<твой_ник>/task-X
   ```

## 🎯 Задания

### Задание: Создание профиля разработчика
**Цель:** Создать первую ветку, добавить файл и отправить его на сервер.

1. Убедись, что ты находишься в своей базовой ветке:
   ```bash
   git checkout feature/<твой_ник>
   ```
2. Создай файл `contributors/<твой_ник>.md` и заполни его по шаблону:
   ```markdown
   # Профиль: [Твоё Имя]
   
   - **Никнейм:** <твой_ник>
   - **Интересы:** [Напиши, что тебе интересно в IT]
   - **Цель:** [Чему хочешь научиться]
   ```
3. Сохрани изменения, сделай коммит и отправь ветку:
   ```bash
   git add contributors/<твой_ник>.md
   git commit -m "Добавил профиль разработчика"
   git push -u origin feature/<твой_ник>
   ```
4. Создай **Merge Request** в GitVerse, чтобы учитель проверил и слил твою базовую ветку.

### Задание: Добавление идеи проекта
**Цель:** Научиться создавать вложенные ветки от своей базовой ветки.

1. Вернись в свою базовую ветку и создай от неё новую для этого задания:
   ```bash
   git checkout feature/<твой_ник>
   git checkout -b feature/<твой_ник>/task-2
   ```
2. Создай папку `ideas` (если её нет) и файл `ideas/<твой_ник>.md`. Напиши в нём идею для любого пет-проекта (например, "Телеграм-бот для напоминаний").
3. Отправь изменения:
   ```bash
   git add ideas/<твой_ник>.md
   git commit -m "Добавил идею проекта"
   git push -u origin feature/<твой_ник>/task-2
   ```
4. Создай **Merge Request** для этой ветки.

### Задание: Работа с черновиками (Stash)
**Цель:** Научиться временно прятать изменения, если нужно срочно переключиться.

1. Создай новую ветку от своей базовой:
   ```bash
   git checkout feature/<твой_ник>
   git checkout -b feature/<твой_ник>/task-3
   ```
2. Открой свой профиль `contributors/<твой_ник>.md` в редакторе `nano` и начни писать туда длинный текст, но **не сохраняй коммит**.
3. Представь, что тебе срочно нужно переключиться. "Заморозь" изменения:
   ```bash
   git stash save "Начатый текст профиля"
   ```
4. Проверь, что файл стал чистым (`git status`).
5. Теперь "разморозь" изменения обратно:
   ```bash
   git stash pop
   ```
6. Заверши работу: сохрани файл, сделай коммит и отправь ветку на сервер. Создай MR.

---

### Задание: Откат изменений (Reset)
**Цель:** Научиться исправлять ошибки и отменять коммиты.

1. Создай новую ветку:
   ```bash
   git checkout feature/<твой_ник>
   git checkout -b feature/<твой_ник>/task-4
   ```
2. Создай файл `temp.txt`, добавь его и сделай коммит:
   ```bash
   echo "Тестовый текст" > temp.txt
   git add temp.txt
   git commit -m "Добавил временный файл"
   ```
3. Осознай, что файл не нужен. Отмени последний коммит, но оставь файл в рабочей директории:
   ```bash
   git reset --soft HEAD~1
   ```
4. Теперь удали файл и забудь о нём полностью (жесткий сброс):
   ```bash
   git restore --staged temp.txt
   rm temp.txt
   ```
5. Сделай коммит с сообщением "Очистил репозиторий от мусора" и отправь ветку. Создай MR.

---

### Задание: Теги и версии (Tags)
**Цель:** Научиться помечать важные этапы работы.

1. Убедись, что ты в своей базовой ветке:
   ```bash
   git checkout feature/<твой_ник>
   ```
2. Создай аннотированный тег для текущей версии твоей ветки:
   ```bash
   git tag -a v1.0 -m "Первая стабильная версия профиля"
   ```
3. Посмотри список своих тегов:
   ```bash
   git tag
   ```
4. Отправь тег на удалённый сервер (обычный push теги не отправляет!):
   ```bash
   git push origin v1.0
   ```
5. Создай задачу (Issue) с заголовком: `Тег v1.0 успешно создан` и опиши, что ты сделал.

## 📚 Шпаргалка полезных команд

**Просмотр состояния:**
```bash
git status                    # Что изменилось?
git log --oneline --graph     # История коммитов
git branch -a                 # Список всех веток
```

**Работа с ветками:**
```bash
git checkout -b <имя_ветки>   # Создать и переключиться
git checkout <имя_ветки>      # Просто переключиться
git merge <имя_ветки>         # Слить ветку в текущую
```

**Отмена изменений:**
```bash
git restore <файл>            # Отменить изменения в файле
git reset --soft HEAD~1       # Отменить коммит (файлы останутся)
git reset --hard HEAD~1       # Отменить коммит и удалить изменения
```

## 🎓 Правила сдачи заданий

1. Каждое задание выполняется в **отдельной ветке**, созданной от твоей базовой ветки `feature/<твой_ник>`.
2. После выполнения задачи всегда создавай **Merge Request** (кроме заданий, где указано создать Issue).
3. В описании Merge Request кратко напиши, что было сделано.
4. Никогда не пушь изменения напрямую в ветку `main`!

Удачи в изучении Git! Если что-то непонятно — создавай Issue с вопросом или спрашивай преподавателя.
